# CNN-Image-Classifier-

A deep learning project that implements a Convolutional Neural Network (CNN) trained on the Fashion-MNIST dataset for image classification.  
This repository includes the full model development pipeline—dataset preparation, preprocessing, training, evaluation, optimization, and model saving—along with a structured project report and placeholders for UI/result images.

---

## 📌 Project Overview

This project demonstrates how to build and train a CNN model capable of classifying 28×28 grayscale fashion images into 10 classes.  
The model is trained using TensorFlow/Keras and achieves strong performance on the test dataset.

The goal is to provide a clear, academic-style deep learning workflow:

- Dataset loading and preprocessing  
- CNN architecture design  
- Training with accuracy/loss visualization  
- Evaluation using confusion matrix & classification report  
- Model optimization  
- Saving the model in `.h5` and SavedModel formats  
- Integration-ready structure for deployment (Flask or API)
